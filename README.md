\# DAJE Atende — MVP de Gestão e Triagem de Orçamentos

Sistema desenvolvido para a parceira comunitária \*\*DAJE Serviços\*\* (Jardim Tremembé, São Paulo - SP), com foco na formalização do atendimento, cálculo automatizado de margem técnica de perda (+10%) e agendamento ágil de visitas de medição. 

## 🎯 Objetivos do MVP - \*\*RF01:\*\* Formulário público simples para solicitação de estimativa de pisos com cálculo de área em tempo real. - \*\*RF02:\*\* Aplicação automática de 10% de margem técnica de perda/quebra de material. - \*\*RF03:\*\* Painel de triagem da gestora com gerador de resposta estruturada para WhatsApp (\`wa.me\`). - \*\*RF04:\*\* Agendamento formal de visitas técnicas presenciais por turnos (Manhã/Tarde). 

## 🛠️ Tecnologias Utilizadas - \*\*Frontend:\*\* PWA (HTML5 semântico, Tailwind CSS, JavaScript Vanilla) com acessibilidade WCAG 2.1 AA. - \*\*Backend:\*\* Python (FastAPI / Uvicorn). - \*\*Banco de Dados:\*\* PostgreSQL (modelagem relacional com integridade referencial). - \*\*Testes &amp; CI:\*\* pytest, flake8 e GitHub Actions.
